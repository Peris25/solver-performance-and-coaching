Threshold Calculations

Edit historical data · API recomputes thresholds live
How thresholds are set (v5): T1 = Best Average (own personal peak), capped at 16/day × 22 days = 352/mo. Best Average uses the regional benchmark (Regent 2024 × 15% market share ÷ headcount) for solvers with ≤1 period of real history. T2 Multiplier shrinks linearly as a solver approaches the 18/day × 22 = 396/mo ceiling. T2 = T1 × Multiplier, capped at 396/mo. Set a Manual Override when you have information outside the model — all changes are audit-logged.
